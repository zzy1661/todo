## 4. quarantine 实验（本阶段判据）

步骤：挂载新 dmg → `ditto` 出 `.app` 到临时目录 → 写 quarantine → 双击（Finder 里打开，等价于双击）→ 全屏截图。

```console
$ hdiutil attach -nobrowse -readonly "…/日程待办_0.1.0_aarch64.dmg"
/dev/disk13s1  Apple_HFS  /Volumes/日程待办

$ ditto "/Volumes/日程待办/日程待办.app" "$TMP/q4/日程待办.app"
$ xattr -w com.apple.quarantine "0083;00000000;Safari;" "$TMP/q4/日程待办.app"
$ xattr -p com.apple.quarantine "$TMP/q4/日程待办.app"
0083;00000000;Safari;

$ osascript -e 'tell application "Finder" to open POSIX file "…/q4/日程待办.app"'
$ screencapture -x docs/verification/desktop/M-01-c-gatekeeper-after-signing.png
```

**观察到的弹框（与 S7.5 对比）**：

| 项 | S7.5（无封条，07:21 类构建） | S7.6（ad-hoc 封条，10:35 构建） |
| --- | --- | --- |
| 正文 | 日程待办.app 已损坏，无法打开。你应该将它移到废纸篓。 | 无法打开"日程待办.app"，因为 Apple 无法检查其是否包含恶意软件。 |
| 补充 | 无 | 此软件需要更新。请联系开发者了解更多信息。/ "Safari" 于未知日期创建了此文件。 |
| 按钮 | 移到废纸篓 / 取消 | 在访达中显示 / 好 |
| 处置 | 只能删或去命令行；「右键 → 打开」不适用 | 关掉后用 `xattr -dr` 放行；「右键 → 打开」属于 macOS 标准放行路径，但**本机未实测** |

截图：`docs/verification/desktop/M-01-c-gatekeeper-after-signing.png`（3024×1964，全屏，含 Finder 里 q4 目录与 `.app`，无敏感内容）。

> 取证口径说明：本机 `tcc.accessibility = false`，`osascript`/CGEvent 合成点击均失败（-25211），
> 所以「双击」用 Finder 的 `open POSIX file` 驱动——它和双击走同一条 LaunchServices/Gatekeeper 路径；
> 这点与 S7.5 相同，不额外声称。
